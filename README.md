## 📌 Descripción del proyecto

**Graphio** es una nueva marca de servicios gráficos e imprenta que surge del cambio de socios de AFERTA SG. Este repositorio contiene el código fuente completo de su página web, desarrollada desde cero como proyecto de prácticas de 1º curso.

La web tiene como objetivos principales:

* Generar contactos a través de formulario y WhatsApp.
* Mostrar el catálogo de servicios de forma clara y profesional.
* Posicionarse en Google para búsquedas del sector gráfico e imprenta.
